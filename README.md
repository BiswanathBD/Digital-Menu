# Digital Menu

> A simple, responsive digital menu card built with Tailwind CSS and JavaScript.

Live demo: https://biswanathbd.github.io/Digital-Menu/

## About

This project is a lightweight digital menu for showcasing food items, categories, and a cart with order placement. It's implemented using plain HTML, CSS (Tailwind via CDN + custom styles), and vanilla JavaScript.

## Features

- Responsive layout with Tailwind CSS
- Category list, food listing, and cart with total
- Simple order placement handler (client-side)

## Run locally

1. Open `index.html` in your browser (double-click or serve with any static server).
2. Or host on GitHub Pages using this repository (demo link above).

## Notes

- Tailwind is included via CDN in `index.html` for convenience.
- Update `assets/` images or `index.js` data to customize menu items.
